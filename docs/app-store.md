## 説明文（日本語・4000文字以内）

```
「SHOOTOUT 4」は、架空の国際PK戦連盟 IPKSF の世界大会を舞台にした、4択・交互攻守のPK対決ゲームです。

■ ルールはシンプル、読み合いは深い
ゴールは4つのコース（左上・右上・左下・右下）に分かれています。
あなたは「狙う方向」か「飛ぶ方向」を選び、8秒以内に決定ボタンで確定。
相手も同時に選んでいて、両方が決まった瞬間に結果が出ます。
同じ方向ならセーブ、違えばゴール。5本ずつ蹴って同点なら、6本目からサドンデス。
残りの本数で追いつけなくなった時点で試合は終わります。

■ 迫力の3Dスタジアム
デイとナイターを切り替えられる3Dスタジアムで、立体ゴールのネットが揺れ、
紙吹雪と歓声がゴールを祝います。キッカー5人とキーパーは3Dモデルで、
選んだユニフォームとスパイクがそのままピッチに反映されます。

■ 32か国と国別の歓声
日本・ブラジル・イングランド・スペイン・ドイツ・イタリア・フランス・アルゼンチン・
ポルトガル・オランダ・クロアチア・モロッコ・韓国・アメリカ・メキシコ・ナイジェリア。
相手の国とCPUの強さ（初級・中級・上級・最強）を選べます。

■ PKスコアボード
先攻・後攻、キッカー1〜5番目、各本の○×、サドンデスが一目で分かります。

■ こだわりのロッカー
ストライプ、タスキ、バイカラー、グラデーション、ゴールドアクセントなど
プロサッカーに近い配色のユニフォーム10種と、スピード・クラシック・ハイカットの
スパイク6種。5人全員が同じユニフォームで揃います。

■ 公平性
ユニフォームもスパイクも、IPKSF 公式加盟（PRO）も、選手の能力や勝敗確率を
1%も変えません。勝敗は、あなたの読みだけです。

■ IPKSF 公式加盟（PRO・買い切り ¥300）
・世界ランキング戦に参戦
・フレンド対戦（ルームコード）
・ユニフォーム＆スパイクの全解放
※ 非消費型（買い切り）です。追加の課金はありません。

■ そのほか
・12言語対応（日本語・英語・簡体字・繁体字・韓国語・スペイン語・ポルトガル語・
  フランス語・ドイツ語・イタリア語・タイ語・インドネシア語）
・音・BGM・バイブの個別ON/OFF
・文字サイズ 標準／大／特大
・オープニング（3秒・スキップ可）
・戦績、遊び方、プライバシーポリシー

※ 本アプリの「IPKSF」および大会名は架空のものです。実在の連盟・大会・選手とは
一切関係ありません。商標・ロゴはすべてオリジナルです。
```
