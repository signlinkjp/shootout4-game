# SHOOTOUT 4 Build 3 修正リスト（トモアキさん実機試遊 Build 2 より）

1. **ホーム画面のヒーロー枠のバランス修正（`IMG_4420`）**
   - 特大文字＋IPKSFカード下部移動に伴い、上部のエンブレム枠が縦に押し潰されてエンブレム下半分・タイトル・対戦国表示が隠れているのを修正する。
   - 左上の `IPKSF` 表記は今のまま維持し、中央のエンブレムマーク＆タイトルをしっかり強調表示する（縦スクロール可または全体余白バランス調整）。

2. **バックグラウンド移行時の音声・BGM完全停止（`IMG_4421`）**
   - iPhone のホーム画面・他アプリへ戻っても Dynamic Island のスピーカーアイコンと BGM が残り続ける問題を修正する。
   - Web側：`visibilitychange`（`document.hidden`）／`pagehide` で即座に BGM・歓声を停止し `AudioContext.suspend()` を呼ぶ。復帰時（`!document.hidden`）のみ再開。
   - iOS側（`AppDelegate.swift`）：`applicationWillResignActive` / `applicationDidEnterBackground` で `AVAudioSession.sharedInstance().setActive(false, options: .notifyOthersOnDeactivation)` を呼び、`applicationDidBecomeActive` で復帰させる。

3. **プレイ中画面の右上ボタン追加（`IMG_4441`）**
   - プレイ中画面の右上に **スピーカー ON/OFF ボタン（🔊/🔇）** と **設定ボタン（⚙️）** を追加する。

4. **試合結果ページの凡例表記の近接配置（`IMG_4442`）**
   - `⚽ シュート` と `🧤 セーブ` が左右両端に離れすぎているため、`⚽ シュート vs 🧤 セーブ` のように近くに並べてわかりやすく表示する（各行は「蹴った選手・利き足・コース・○/×」がすぐ読める形を維持）。

5. **ロッカーに「先攻 / 後攻」選択ボタン追加＆スコア/PK表の統一**
   - ロッカーに **先攻 / 後攻** の選択ボタンを追加する（CPU戦等で反映）。
   - ゲーム中の上部スコアボードは **左側＝ユーザー、右側＝相手** で固定表記。
   - PK表（◯/×）は **上段＝先攻、下段＝後攻** で固定し、**どちらがユーザーでどちらが相手かも一目でわかるラベル**（「あなた（先攻）」「相手（後攻）」や国旗など）を付ける。

6. **戦績画面を「CPU戦績（リセット可）」と「PRO 通信対戦通算成績」の2本立てに**
   - CPUとの対戦成績は今のまま **リセット可能** な形で維持する。
   - PROモードには、**対人（相手がいる通信対戦）の通算成績** を別枠で記録・表示する。

7. **キーパーのダイビング方向と体勢の修正**
   - 実機動画（`attachments/2026-11-27/ScreenRecording_11-27-2026 00-15-25_1-96fbaf2922f047b4b1d0b9d36273ade3.mp4`）で「キーパーの飛んでいく方向と体勢がおかしい」との指摘。
   - ゴール位置・キッカー視点／キーパー視点のどちらから見ても、選んだコース（左上／右上／左下／右下）に向かって、頭と手がボール側・足が反対側になる自然な横飛び／上飛びダイビング体勢に直す。
   - Build 3 完了後は、トモアキさんとの合意どおり **自動 TestFlight 発火はせず**、`origin/main` push 後に報告して合図を待つ（または次の修正要望を受けてからまとめてビルドする）。
8. **「国をえらぶ」画面の横スクロール案内追加（`IMG_4444`）**
   - 「あなたの国」の横列が4か国ピッタリで、右にまだ16か国（PROは32か国）あることに気付きにくい。
   - 「あなたの国」「対戦相手」の見出しの右側に `← 横スクロール →` のような案内を出す（12言語対応）。
9. **ロッカー画面の3Dプレビューでキャラ違い（ブロック型 / スタイリッシュ型）を分かりやすく**
   - 無料（ブロック）と PRO（スタイリッシュ）を選んでも、上の見た目の違いに気付きにくい。
   - プレビューを近く・見やすい角度（斜め正面のアップ寄り）にし、**表示中のキャラ名バッジ**（例: `ブロック（無料）` / `スタイリッシュ（PRO）`）を枠内に出す。
   - 切替時はキャラが軽く回転／ジャンプする演出を入れて、切り替えた瞬間の違いが一目で分かるようにする。
